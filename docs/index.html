Setup — Step 1

Pin the extension to the toolbar

Without pinning, HushDown stays hidden; you'd have to open the 🧩 menu every time.

1
Click the puzzle piece icon

Find the 🧩 icon on the right side of Chrome's address bar and click it to open the extension list.

2
Find HushDown

Locate HushDown in the list.

3
Click the pin icon

Click the 📌 pin icon next to HushDown. It will now appear in your toolbar.

Setup — Step 2

Allow Chrome notifications

To receive preview notifications when a download completes, Windows needs permission to show Chrome notifications.

1
Open Windows Settings

Press Windows + I or open Settings from the Start menu.

2
System → Notifications

Go to System, then select Notifications.

3
Turn on Google Chrome

Find Google Chrome in the app list and set notifications to On.

Setup — Step 3 (optional)

Enable image previews

To see inline previews of downloaded images in notifications and the download list, grant the extension access to local files.

1
Open extension management

Type chrome://extensions in the address bar.

2
HushDown → Details

Click the Details button on the HushDown card.

3
Enable "Allow access to file URLs"

Scroll down and toggle Allow access to file URLs on.

How it works

What does HushDown do?

It runs quietly in the background — no action needed from you.

⬇️
Automatic renaming

Every download is saved as yyyyMMddHHmmss-your-original-name.ext: a sortable timestamp prefix, then the suggested filename from the site (invalid characters are replaced). If the name has no extension, one may be inferred from the file type.

🔔
Preview notifications

A desktop notification appears when a download completes. For images, the picture itself is shown as a preview. Click the notification to reveal the file in its folder.

🗂️
Last 10 downloads

Open the extension to see the last 10 downloads. Click a row to open the file. Images show a small thumbnail. Use × to remove an entry from the list.

📁
Download folder

Files are saved to Chrome's default Downloads folder. Change it anytime via chrome://settings/downloads.

FAQ

Frequently asked questions


Will my existing files be affected?
No. HushDown only affects new downloads. Files already on your disk are never touched.
How do I change the download location?
Type chrome://settings/downloads in the address bar and change the Location. HushDown always saves files to Chrome's current default download folder.
I get a notification but no image preview.
Preview requires local file access.

Go to chrome://extensions → HushDown → Details → enable "Allow access to file URLs".
Can I turn off notifications?
Yes — go to Windows Settings → System → Notifications → Google Chrome and turn it off. Note that this disables all Chrome notifications, not just HushDown's.
What permissions does HushDown use?
downloads — Set filenames and read download history.
downloads.open — Open files from the list.
storage — Save the download log and thumbnails.
notifications — Show desktop notifications.
offscreen — Generate image previews (invisible background page).
file:///* — Read downloaded images to generate previews (optional, user-granted).
