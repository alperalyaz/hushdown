HushDown — Privacy Policy

Last updated: 14 May 2026 · Open source: GitHub

HushDown is a Chrome extension developed on behalf of Hidroteknik. This policy describes how the extension handles information. HushDown does not operate its own backend for collecting or storing your personal data on our servers.

1. What the extension does

HushDown suggests a filename when you download a file (timestamp prefix plus the original suggested name), may show a desktop notification when a download completes, and shows a short list of recent downloads in the extension popup. These features use only your browser’s extension APIs and local storage as described below.

2. Data stored on your device

All data below stays under your control via Chrome. It is not transmitted to Hidroteknik or third-party analytics servers by the extension.

  • Chrome storage.sync: a small list (last 10) of completed download labels (display name and time) for the popup.
  • Chrome storage.local: small image thumbnail data for recent downloads, used only to show previews in the popup.

Chrome may sync storage.sync data across your signed-in Chrome devices according to Google’s own sync and account policies.

3. Permissions (why they exist)

  • downloads — to apply the suggested filename on new downloads and to read basic download metadata after completion (log, notifications, optional file removal when you delete an entry from the list).
  • downloads.open — only when you choose to open a file from the list or related UI.
  • storage — to persist the short download log and thumbnails as above.
  • notifications — to show download-complete notifications.
  • offscreen — to convert a locally saved image into a format usable for rich notifications (invisible helper page bundled with the extension).
  • file:///* (optional) — only if you enable “Allow access to file URLs” for HushDown in chrome://extensions, so the extension can read downloaded image files from disk to build previews. No remote browsing of your files.

4. Remote code

The extension’s executable logic is contained in the extension package submitted to the Chrome Web Store. HushDown does not load or execute remote JavaScript for its core functionality. Opening the welcome or documentation site in a normal browser tab is ordinary web browsing, not remote code inside the extension.

5. Third parties, sale of data

We do not sell your personal information. We do not use an extension-specific analytics pipeline to send your download history or file contents to Hidroteknik. Google operates the Chrome Web Store and the browser; their terms and privacy policies apply to Chrome itself.

6. Children’s privacy

HushDown is not directed at children under 13, and we do not knowingly collect personal information from children for this project.

7. Changes

We may update this policy when the extension or legal requirements change. The “Last updated” date at the top will be revised accordingly.

8. Contact
