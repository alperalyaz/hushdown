HushDown — Privacy Policy

Last updated: 12 October 2026 · Open source: GitHub

HushDown is a Chrome extension developed on behalf of Hidroteknik. This policy describes how the extension handles information. HushDown does not operate its own backend for collecting or storing your personal data on our servers.

1. What the extension does

HushDown suggests a folder and filename when you download a file. If you started a project in the popup, or the tab is in a named Chrome tab group, the file is saved in a folder for that project with a numbered name, and a sources list is kept for the folder. Otherwise it keeps the normal filename and only renames meaningless ones. The popup shows a searchable list of recent downloads, and an optional notification (off by default) can appear when a download completes. These features use only your browser’s extension APIs, local storage and your Downloads folder, as described below.

2. Data stored on your device

All data below stays under your control via Chrome and your own disk. It is not transmitted to Hidroteknik or third-party analytics servers by the extension. HushDown has no servers and no accounts.

  • Chrome storage.sync: your settings, the active project name and a short list of recent project names.
  • Chrome storage.local: the download history shown in the popup (up to 200 entries: file name, time and project), small image thumbnails for those entries, per-project file counters, and the sources list for each project.
  • Sources list: for each file saved into a project folder, its number and file name, the address of the page it came from, the file’s download address and the access date. The same list is written as a text file (for example _sources.txt) into that project’s folder in your Downloads folder.

Chrome may sync storage.sync data across your signed-in Chrome devices according to Google’s own sync and account policies. Removing an entry from the popup list removes it from the history only; it does not delete the file.

3. Permissions (why they exist)

  • downloads — to apply the suggested folder and filename on new downloads, to read basic download metadata after completion (history, sources list, optional notifications), and to write the sources text file and keep it out of Chrome’s download list.
  • downloads.open — only when you choose to open a file from the list or related UI.
  • storage — to persist settings, history, thumbnails and the sources list as above.
  • notifications — to show an optional download-complete notification (off by default).
  • offscreen — to make image thumbnails from a locally saved image (invisible helper page bundled with the extension).
  • tabGroups — to read the name of the active tab’s group, so a named group can be used as the project folder.
  • file:///* (optional) — only if you enable “Allow access to file URLs” for HushDown in chrome://extensions, so the extension can read downloaded image files from disk to build thumbnails. No remote browsing of your files.

The tabs permission is optional. HushDown asks for it once, when you start your first project. If you allow it, HushDown reads the address and title of the tab a file is downloaded from, at that moment only, and writes them to the sources list on your computer. Chrome describes this permission as “Read your browsing history”; HushDown does not read your history and sends nothing anywhere. If you do not allow it, the page address comes from the download itself (its referrer), which browsers often shorten to the site root.

4. Remote code

The extension’s executable logic is contained in the extension package submitted to the Chrome Web Store. HushDown does not load or execute remote JavaScript for its core functionality. Opening the welcome or documentation site in a normal browser tab is ordinary web browsing, not remote code inside the extension.

5. Third parties, sale of data

We do not sell your personal information. We do not use an extension-specific analytics pipeline to send your download history or file contents to Hidroteknik. Google operates the Chrome Web Store and the browser; their terms and privacy policies apply to Chrome itself.

6. Children’s privacy

HushDown is not directed at children under 13, and we do not knowingly collect personal information from children for this project.

7. Changes

We may update this policy when the extension or legal requirements change. The “Last updated” date at the top will be revised accordingly.
