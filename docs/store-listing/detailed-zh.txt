HushDown — 按项目而不是按文件类型整理下载

为了写作业，从十几个网站收集图片、PDF 和笔记？这些文件通常以“image931.png”“download (3).pdf”“IMG_20240101_1234.jpg”之类的名字堆在下载文件夹里，过后也想不起来各自出自哪里。HushDown 按您正在做的事情整理下载，而不是按文件类型：告诉它您在做什么项目，每个文件都会存入该项目的文件夹，带有清楚的编号文件名，并自动生成来源清单。

为什么选择 HushDown？

• 每个项目一个文件夹 — 在弹窗中输入项目名称，例如“生物作业”，然后点击“开始”。在点击“结束”之前，所有下载都会存入 下载/生物作业/。最近的项目会显示为标签，一键即可重新开始。

• 统一的编号文件名 — 文件按 <项目>_<编号>_<名称> 命名，例如 生物作业_001_线粒体.png、生物作业_002_week4-notes.pdf。编号保留您收集文件的先后顺序。

• 有意义的名称 — 网站提供的文件名有意义时会保留，但会整理格式（“Week4 Notes.pdf” → week4-notes.pdf）。image931.png、download (3)、IMG_20240101_1234、哈希值或 UUID、“unnamed”、“WhatsApp Image ...”这类无意义的名称，会替换为页面地址中的主题：从 zh.wikipedia.org/wiki/线粒体 下载的文件会命名为“线粒体”。

• 自动来源清单 — 每个项目文件夹中都有一个 _来源.txt，列出每个文件的编号、来源页面、文件网址和访问日期。也可以一键复制到剪贴板。

• 标签页分组即项目 — 如果标签页属于已命名的 Chrome 标签页分组，从中下载的文件会自动存入以分组名称命名的文件夹，无需打开弹窗。

• 无需账号、无广告、无订阅 — 免费且开源。

工作原理

下载开始时，HushDown 会决定文件存入哪个文件夹、使用什么名称：

1. 如果当前标签页属于已命名的标签页分组，则以分组名称作为项目。（已命名分组优先于弹窗中的项目。可在弹窗中关闭：“将标签页分组名称用作项目”。）
2. 否则，如果您在弹窗中开始了项目，则使用该项目。
3. 既没有项目也没有已命名分组时，HushDown 不做多余改动：保留正常的文件名，只把无意义的名称改为 <主题>_<yyMMdd-HHmmss>，例如 线粒体_261012-140305.png。

项目文件夹创建在 Chrome 的默认下载文件夹中 — 可随时在 chrome://settings/downloads 中更改位置。来源清单在每次下载后自动重写，并且不会出现在 Chrome 的下载列表中。仅影响新下载；不会修改磁盘上已有文件。

弹窗还会列出最近 200 次下载，图片显示缩略图，每条都标有所属项目。可按文件名或项目名搜索，点击打开文件，或用 × 从列表中移除该行（不会删除文件）。下载完成时的桌面通知为可选功能，默认关闭。

语言

扩展界面：简体中文、英语、土耳其语（跟随 Chrome 语言设置）。来源文件相应命名为 _来源.txt、_sources.txt 或 _kaynaklar.txt。

权限说明

• downloads — 重命名新下载并获知下载完成
• downloads.open — 在列表中点击时打开文件
• storage — 保存设置、下载记录、来源清单和缩略图（本地 / Chrome 同步）
• notifications — 可选的下载完成通知
• offscreen — 在扩展内部生成图片缩略图
• tabGroups — 读取当前标签页所属分组的名称
• file://（可选，用户手动开启）— 本地读取已下载图片以生成缩略图

tabs（可选）— 在你开始第一个项目时询问一次，用于在来源清单中记录下载所在标签页的完整地址和标题。Chrome 会将其显示为“读取您的浏览记录”；HushDown 只在下载时查看该标签页，不会发送任何数据。若不授权，页面地址取自下载本身，通常只保留网站根地址。

快速开始

1. 安装 HushDown 并固定到工具栏（拼图图标 → 固定）。
2. 打开弹窗，输入您正在做的项目，点击“开始”。
3. 照常下载文件，然后查看 下载/<项目名称>/ 文件夹及其中的 _来源.txt。
4. 可选：开启“允许访问文件网址”（chrome://extensions → HushDown → 详细信息）以显示图片缩略图，并在弹窗中开启通知。

常见问题

会更改下载文件夹吗？
不会 — 项目文件夹创建在 Chrome 的下载文件夹中。位置仍由 Chrome 设置决定。

没有进行中的项目时会怎样？
保留正常的文件名；只把无意义的名称改为 <主题>_<日期时间>。

会重命名已有文件吗？
不会 — 仅影响安装后的新下载。从下载记录中移除某一行不会删除文件。

时间戳命名模式和按文件类型分文件夹的功能去哪了？
2.0 版本已移除这些功能。现在按项目整理下载。

可以开启或关闭通知吗？
可以 — 在弹窗中设置。默认关闭。

免费吗？
是的。Hidroteknik 实验性项目，无商业模式。
