HushDown — 为每次 Chrome 下载自动添加时间戳文件名

下载文件夹里满是“图片 (1).png”“文档 (2).pdf”和难懂的服务器文件名？HushDown 在后台静默运行，为每个新下载重命名，便于排序、查找和归档 — 不改变您的正常浏览方式。

为什么选择 HushDown？

• 默认可排序 — 文件名以 yyMMdd-HHmmss（年月日时分秒）开头，下载文件夹按真实时间顺序排列。

• 多种命名方式 — 在扩展弹窗中选择三种模式：仅时间戳、时间戳 + 原始名称，或仅原始名称。

• 丰富通知 — 下载完成时提醒；图片文件在允许时可显示预览通知。

• 最近 10 次下载 — 弹窗中快速查看列表；图片显示缩略图，可打开文件或从列表移除。

• 无需账号、无广告、无订阅 — 免费且开源。

三种文件名模式

1. 时间戳（默认）— 示例：20260514153045.png

2. 时间戳 + 原始名称 — 示例：20260514153045-invoice.pdf

3. 原始名称 — 保留网站建议的文件名（经清理），不添加时间戳

可随时在工具栏扩展图标弹窗中切换模式。登录 Chrome 后，偏好可在设备间同步。

工作原理

HushDown 在下载开始时建议新文件名。文件仍保存到 Chrome 默认下载文件夹 — 可在 chrome://settings/downloads 中更改位置。仅影响新下载；不会修改磁盘上已有文件。

通知与图片预览

下载完成后，HushDown 可显示桌面通知。图片预览请在扩展详情页（chrome://extensions）开启“允许访问文件网址”。预览仅在本地设备生成 — 不会上传到外部服务器。

• 简短最近列表（最近 10 条）和可选缩略图保存在 Chrome 本地存储

语言

扩展界面：简体中文、英语、土耳其语（跟随 Chrome 语言设置）。

权限说明

• downloads — 重命名新下载并读取完成信息
• downloads.open — 在列表中点击时打开文件
• storage — 保存最近下载列表和缩略图
• notifications — 下载完成提醒
• offscreen — 生成通知图片预览（内置辅助页面）
• file://（可选，用户手动开启）— 本地读取已下载图片以生成预览

快速开始

1. 安装 HushDown 并固定到工具栏（拼图图标 → 固定）。
2. 在弹窗中选择文件名模式。
3. 下载任意文件并查看下载文件夹。
4. 可选：允许 Chrome 通知和文件网址访问以显示图片预览。

常见问题

会更改下载文件夹吗？
不会 — 仅更改文件名。文件夹路径仍由 Chrome 设置决定。

会重命名已有文件吗？
不会 — 仅影响安装后的新下载。

可以关闭通知吗？
可以 — 在 Windows 或 Chrome 通知设置中关闭。

免费吗？
是的。Hidroteknik 实验性项目，无商业模式。
